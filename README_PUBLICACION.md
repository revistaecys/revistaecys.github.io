# Inicio profesional de Revista ECYS

Esta carpeta contiene únicamente los archivos de la raíz actualizados. Copia `index.html` a la raíz del repositorio `revistaecys.github.io`, sustituyendo solo el archivo anterior. No elimines las carpetas de ediciones anteriores. Mantén `29Edicion/` en la misma raíz para que el visor y el enlace al PDF funcionen.

Los archivos `.jekyllignore` y `google5029b875cce6dc89.html` se incluyen sin cambios.

Se conserva el identificador de Google Analytics **G-V6HS3KRG7S** de la página principal. La edición XXIX puede requerir una propiedad y un ID propios configurados dentro de `29Edicion/`.

Puedes navegar por las ediciones, buscarlas por número o nombre y abrirlas por separado. La URL puede usarse con `#edicion=28`, por ejemplo. Los navegadores que bloqueen contenido incrustado pueden abrir la revista con **Abrir edición**.

Para probar localmente, coloca `index.html` al lado de la carpeta `29Edicion`. Para publicar, desde el repositorio:

```bash
git status
git add index.html
git commit -m "Renovar portada principal ECYS y destacar edicion XXIX"
git push origin master
```

No publiques hasta verificar que todos los archivos de `29Edicion/` están en el repositorio.
